lr-gpsp-nspire
Standalone Libretro gpsp for nSpire calculators
-----------------------------------------------

This is a standalone version of gpsp based on Libretro gpsp (commit 6373ff3) for nSpire calculators (CX, CX CAS, CX II etc)

The GUI and ancillary code has been taken from the 'normal' gpsp and combined with the Libretro core, to (hopefully) create a version with high game-compatability but without the overhead of a Libretro frontend.

To build this you will need the Ndless SDK.

It is highly likely that there are bugs and 'features' - also at the time of writing I don't know how this will be performance-wise as have only been able to test on the Firebird Emulator.  Your mileage may vary!!!
